Peluche ID

A Trans Jam 2026 by OUTRANS entry


Overview

Goal

Peluche ID is a game about making ID documents by completing puzzles that contains geometrical constraints.

Controls

Mouse: Interact


Terminology

  • Adjacent: Orthogonally touching
  • Item: Document item, (A L piece is one single item)
